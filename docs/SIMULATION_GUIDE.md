# 小财进 - 模拟交易系统使用指南

## 📊 系统概述

小财进模拟交易系统是一个基于真实 ETF 数据的理财学习平台，帮助用户在零风险的环境中学习基金投资。

### 核心特性

✅ **真实数据** - 基于 CMES ETF 数据，经过平滑处理
✅ **零风险** - 10 万元虚拟资金，完全无损练习
✅ **19 只精选基金** - 涵盖货币、债券、指数、行业等多种类型
✅ **完整交易流程** - 买入、卖出、持仓管理、交易记录
✅ **实时排行榜** - 日收益榜、月收益榜、热门榜、稳健榜

## 🚀 快速开始

### 1. 数据同步

首次使用前，需要同步基金数据：

```bash
cd D:\Users\caixiaojin
npm run funds:sync
```

**建议**：每天收盘后（18:00）运行一次，保持数据最新。

### 2. 启动开发服务器

```bash
npm run dev
```

然后访问：http://localhost:3100

### 3. 进入模拟交易

方式一：直接访问
- http://localhost:3100/tools/simulation

方式二：从工具箱进入
- 访问 http://localhost:3100/tools
- 点击"模拟交易"卡片

## 📖 功能使用说明

### 基金市场 (`/tools/fund-market`)

**功能**：浏览所有可交易基金，查看排行榜

#### 热门榜单

系统提供 4 个排行榜：

1. **今日收益榜** - 按当日收益率排序
2. **月收益榜** - 按近 1 个月收益率排序
3. **综合热门榜** - 综合日收益和月收益的加权排序
4. **稳健收益榜** - 低风险高收益基金

#### 搜索和筛选

- **搜索**：支持基金名称、代码搜索
- **类型筛选**：货币型、债券型、指数型、行业主题、混合型
- **排序**：日收益、月收益、低波动

### 模拟交易 (`/tools/simulation`)

#### 买入基金

1. 在首页选择基金
   - 方式一：在搜索框中搜索并选择
   - 方式二：从"基金市场"点击选择

2. 输入买入金额（最低 100 元）

3. 点击"买入"按钮

4. 系统会显示：
   - 当前净值
   - 可买份额
   - 确认信息

#### 查看持仓

切换到"我的持仓"标签，可以查看：

- **投入本金**：你投入的总金额
- **当前市值**：按最新净值计算的价值
- **浮动收益**：未实现盈亏
- **收益率**：盈亏百分比

#### 卖出基金

1. 在"我的持仓"中找到要卖出的基金

2. 点击"卖出"按钮

3. 系统会自动：
   - 计算卖出金额
   - 更新持仓
   - 记录交易

#### 交易记录

切换到"交易记录"标签，可以查看所有历史交易：

- 买入记录（粉色）
- 卖出记录（绿色）
- 交易时间、份额、净值

## 💡 投资建议

### 新手建议

1. **从货币型开始**
   - 几乎零风险，熟悉交易流程
   - 积累信心

2. **尝试指数型定投**
   - 选择沪深300ETF或中证500ETF
   - 定期买入，平摊成本
   - 长期持有

3. **控制风险**
   - 不要把所有资金买入一只基金
   - 分散投资，降低风险

### 进阶建议

1. **配置资产组合**
   - 货币型 20%：应急资金
   - 债券型 30%：稳健收益
   - 指数型 40%：长期增长
   - 行业主题 10%：博取高收益

2. **关注估值**
   - 市场低位时多买
   - 市场高位时少买
   - 不要追涨杀跌

3. **长期持有**
   - 基金投资适合长期
   - 频繁交易会增加成本
   - 至少持有 1 年以上

## 📊 数据说明

### 数据来源

- **主要来源**：CMES 数据库（专业金融数据服务）
- **数据类型**：ETF 实时行情和历史数据
- **处理方式**：平滑处理，降低波动性

### 更新频率

- **手动更新**：运行 `npm run funds:sync`
- **建议频率**：每个交易日收盘后（18:00）
- **数据保留**：最近 60 天的历史数据

### 数据指标

每只基金提供以下指标：

| 指标 | 说明 | 用途 |
|------|------|------|
| 最新净值 | 当天收盘后的净值 | 计算买入份额 |
| 日涨跌幅 | 当天的收益率 | 判断短期走势 |
| 周收益率 | 近 5 个交易日收益 | 判断短期趋势 |
| 月收益率 | 近 20 个交易日收益 | 判断中期趋势 |
| 季度收益率 | 近 60 个交易日收益 | 判断长期趋势 |
| 最大回撤 | 历史上最大亏损幅度 | 评估风险 |
| 波动率 | 净值波动幅度（年化） | 评估稳定性 |

### 免责声明

1. **模拟性质**：本系统为模拟交易平台，所有交易均为虚拟，无真实资金

2. **学习目的**：系统仅供学习理财知识使用，不构成投资建议

4. **风险提示**：

4. **数据准确性**：仅供参考，不保证完全准确

## 🔧 常见问题

### Q1: 为什么有些基金数据获取失败？

**A**: 可能的原因：
- ETF 代码错误或已退市
- 网络连接问题
- CMES API 限制

**解决方法**：
- 重新运行数据同步
- 检查网络连接
- 联系管理员

### Q2: 为什么我的数据和真实市场不一样？

**A**:
- 我们对 ETF 数据进行了平滑处理
- 模拟的是场外基金（不是 ETF）
- 波动性降低，更适合学习

### Q3: 可以设置自动定投吗？

**A**: 当前版本不支持，未来可能会添加：
- 自动定投功能
- 止盈止损设置
- 价格提醒

### Q4: 数据多久更新一次？

**A**:
- 需要手动运行 `npm run funds:sync`
- 建议每天 18:00 运行一次
- 可以设置定时任务自动运行

### Q5: 可以模拟真实基金购买吗？

**A**:
- 当前版本仅支持模拟交易
- 不提供真实基金购买渠道
- 如需购买，请通过正规基金平台
