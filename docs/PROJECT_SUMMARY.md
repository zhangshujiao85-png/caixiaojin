## 📊 系统架构

### 数据流程图

```
CMES API (ETF数据)
    ↓
Python 同步脚本
    ↓
数据平滑处理
    ↓
计算各种指标
    ↓
生成排行榜
    ↓
保存到 JSON (data/funds.json)
    ↓
Next.js API 路由
    ↓
前端页面读取
    ↓
用户交互
```

### 技术栈

**后端**
- Python 3.11
- cmesdata 库（CMES 官方 SDK）
- pandas（数据处理）
- numpy（数值计算）

**前端**
- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS
- Radix UI
- Framer Motion
- Zustand（状态管理）

**数据**
- JSON 文件存储
- localStorage（用户数据）
- CMES 数据库（外部）

## 💡 核心特性

### 1. 真实数据

- 基于 CMES ETF 数据
- 每天可更新
- 90 天历史数据
- 近 60 天平滑后数据

### 2. 平滑处理

**算法**：
```
daily_return = (etf_change * volatility_factor) + (base_return * (1 - volatility_factor))
```

**效果**：
- 货币型：波动系数 0.1，几乎无波动
- 债券型：波动系数 0.3，小幅波动
- 指数型：波动系数 0.6，适中波动
- 行业主题：波动系数 0.7，较大波动

### 3. 风险分级

- **R1（低风险）**：货币型，适合保本
- **R2（中低风险）**：债券型，适合稳健
- **R3（中等风险）**：指数型、混合型，适合成长
- **R4（较高风险）**：行业主题，适合激进

## 🚀 使用方式

### 开发环境

1. **同步数据**（首次使用）
```bash
npm run funds:sync
```

2. **启动开发服务器**
```bash
npm run dev
```

3. **访问页面**
- 基金市场：http://localhost:3100/tools/fund-market
- 模拟交易：http://localhost:3100/tools/simulation

### 生产环境

1. **设置定时任务**（可选）
- Windows 任务计划程序
- Linux Cron
- GitHub Actions

2. **定期更新数据**
```bash
npm run funds:sync
```

3. **部署到 Vercel**
```bash
npm run build
vercel deploy
```
